# microGPT (Go 포팅)

Andrej Karpathy의 [microGPT](https://karpathy.github.io/2026/02/12/microgpt/)를
Go 표준 라이브러리만으로 포팅한 예제다. 스칼라 자동미분 엔진 위에
작은 GPT(파라미터 약 4,200개)를 만들어 영어 이름 데이터로 학습하고,
학습이 끝나면 새 이름을 생성한다.

## 실행 방법

```bash
go run .
```

외부 모듈 의존성이 없으므로 Go만 설치되어 있으면 바로 실행된다.
난수 시드가 고정되어 있어 실행할 때마다 같은 결과가 나온다.
일반적인 데스크톱 환경에서 30초 안팎이 걸린다.

## 예상 출력

```text
데이터 2000건, 어휘 크기 27, 파라미터 4192개
스텝    1 | 평균 손실 3.3256
스텝  100 | 평균 손실 2.6939
스텝  200 | 평균 손실 2.5538
...
스텝 1500 | 평균 손실 2.3023

생성된 이름 20개:
isala
rilana
motia
ratana
...
```

- 초기 손실은 ln(27) ≈ 3.3 근처다. 어휘 27개 중 하나를 무작위로 찍을 때의 손실이다.
- 1500 스텝 학습 후 손실은 2.3 근처까지 내려간다.
- 생성된 이름은 데이터셋에 없는 새 조합이지만 이름처럼 읽힌다.

## 파일 구성

| 파일 | 내용 |
|------|------|
| `value.go` | 스칼라 자동미분 엔진. `Value` 구조체가 값, 기울기, 역전파 클로저를 담는다. `Backward()`는 연산 그래프를 위상 정렬한 뒤 체인 룰로 기울기를 전파한다. |
| `tokenizer.go` | 문자 단위 토크나이저. 소문자 알파벳 26자에 BOS 특수 토큰을 더해 어휘 크기 27을 만든다. |
| `model.go` | GPT 모델. 토큰 임베딩 + 위치 임베딩, 멀티헤드(2 heads) causal self-attention, tanh MLP 블록, 잔차 연결, rmsnorm, 최종 lm_head. 크기는 n_embd 16, n_layer 1, block size 16. |
| `main.go` | 학습 루프(교차 엔트로피 손실, Adam 옵티마이저, 학습률 선형 감소)와 샘플링(BOS로 시작, temperature 0.8, BOS가 나오면 종료). |
| `names.txt` | 학습 데이터. [makemore의 names.txt](https://github.com/karpathy/makemore) 앞 2000줄. |

## 동작 개요

1. 이름 하나를 골라 `[BOS] + 문자들 + [BOS]` 시퀀스를 만든다.
2. 각 위치에서 다음 토큰의 확률 분포를 계산하고 교차 엔트로피 손실을 구한다.
3. `Backward()`로 모든 파라미터의 기울기를 계산한 뒤 Adam으로 갱신한다.
4. 1500 스텝을 반복하고, 학습이 끝나면 BOS에서 시작해 이름 20개를 생성한다.
