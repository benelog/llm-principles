# minirag: 하이브리드 검색 파이프라인

RAG 파이프라인의 검색 부분을 JDK 표준 라이브러리만으로 구현한 예제다.
가상의 사내 문서 3개를 청킹하고, 같은 청크를 BM25 역색인과 TF-IDF 벡터 인덱스로
색인한 뒤, 두 검색 결과를 RRF(Reciprocal Rank Fusion)로 합쳐 LLM에 보낼 프롬프트를 조립한다.

## 실행 방법

```bash
java Main.java
```

JDK 22 이상의 다중 파일 소스 실행기로 실행되므로 빌드 도구가 필요 없다.
JDK 21에서는 `javac -d out *.java && java -cp out Main`으로 실행한다.
외부 라이브러리 의존성이 없고 실행 결과는 항상 같다.

## 파일 구성

| 파일 | 내용 |
|------|------|
| `Chunk.java` | 청크 레코드. 문장 경계를 찾아 나눈 뒤 최대 길이 이하로 문장을 이어 붙인다. |
| `Tokenizer.java` | 문자 바이그램 토크나이저. 형태소 분석기 없이 한국어 조사 문제를 우회한다. |
| `SearchResult.java` | 검색 방식과 무관한 공통 결과 형식과 상위 k개 선별. |
| `Bm25Index.java` | 키워드 검색용 역색인과 BM25 점수 계산. |
| `VectorIndex.java` | TF-IDF 희소 벡터 인덱스와 코사인 유사도 검색. |
| `Rrf.java` | 두 검색 결과를 순위 기반으로 합치는 RRF. |
| `Main.java` | 청킹 → 색인 → 질의 → 프롬프트 조립 파이프라인. |
