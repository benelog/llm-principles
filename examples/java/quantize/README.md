# 양자화 오차 측정

양자화 알고리즘의 원리를 측정으로 확인하는 예제다. JDK 표준 라이브러리만으로 세 가지를 구현하고 오차를 잰다.

1. **선형 양자화**: 최대 절댓값이 정수 범위의 끝에 오도록 배율을 정하고 반올림한다. INT8과 4비트를 비교한다.
2. **블록 단위 배율**: 아웃라이어 하나가 텐서 전체의 격자를 성기게 만드는 문제를, 64개 블록마다 배율을 따로 두어 막는다.
3. **정규 분포 분위수 격자**: 같은 16개 격자점을 균등 간격으로 둘 때와 정규 분포의 분위수에 둘 때(NF4의 아이디어)를 비교한다.

표준편차 1.0인 정규 분포에서 뽑은 가중치 4,096개를 쓰며, 난수 시드를 고정했으므로 출력이 그대로 재현된다.

## 실행 방법

```bash
java Main.java
```

JDK 22 이상이면 컴파일 없이 바로 실행된다.

## 실행 결과

```text
== 선형 양자화 (표준편차 1.0인 가중치 4,096개) ==
INT8 (격자 255개):  RMS 오차 0.0084
4비트 (격자 15개):  RMS 오차 0.1541

== 아웃라이어 하나가 끼면 (w[0]을 20.0으로) ==
4비트, 텐서 전체에 배율 하나:  RMS 오차 0.7799
4비트, 64개 블록마다 배율:     RMS 오차 0.1340

== 격자를 어디에 둘 것인가 (아웃라이어 없는 원본, 격자 16개) ==
균등 간격 격자:         RMS 오차 0.1424
정규 분포 분위수 격자:  RMS 오차 0.1058
```

## 파일 구성

- `Main.java`: `quantizeAbsmax`와 `dequantize`(선형 양자화), `quantizeBlocks`(블록 배율), `normalGrid`와 `uniformGrid`와 `quantizeGrid`(격자 배치), 오차 측정 전부

JDK에는 정규 분포 누적 함수의 역함수가 없으므로 `inverseNormalCdf`를 Acklam의 유리 함수 근사로 직접 구현했다.
