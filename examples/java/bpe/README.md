# BPE 토크나이저

BPE(Byte Pair Encoding) 토크나이저의 최소 구현이다. 코퍼스에서 가장 자주 등장하는 인접 토큰 쌍을 반복해서 병합하는 학습과, 학습된 병합 규칙을 같은 순서로 재생하는 인코딩으로 이루어진다. 작은 한국어 코퍼스로 12번 병합을 학습시킨 뒤 새 문장을 인코딩한다. 공백은 SentencePiece 방식대로 `▁` 문자로 바꿔서 병합에 참여시킨다.

## 실행 방법

```bash
java Main.java
```

JDK 22 이상이면 컴파일 없이 바로 실행된다. 빈도가 같은 쌍은 사전순으로 고르므로 실행할 때마다 같은 결과가 나온다.

## 실행 결과

```text
== 학습된 병합 규칙 (적용 순서대로) ==
 1: "다" + "▁" -> "다▁"
 2: "은" + "행" -> "은행"
 3: "학" + "교" -> "학교"
 4: "▁" + "만" -> "▁만"
 5: "▁" + "좋" -> "▁좋"
 6: "▁" + "크" -> "▁크"
 7: "▁만" + "나" -> "▁만나"
 8: "▁만나" + "자" -> "▁만나자"
 9: "▁좋" + "다▁" -> "▁좋다▁"
10: "▁크" + "다▁" -> "▁크다▁"
11: "서" + "▁만나자" -> "서▁만나자"
12: "에" + "서▁만나자" -> "에서▁만나자"

== 인코딩 ==
"은행에서 보자" -> ["은행" "에" "서" "▁" "보" "자"]
"은행나무" -> ["은행" "나" "무"]
```

- `Main.java`: 병합 학습 `train`과 `mostFrequentPair`, 인코딩 `encode`와 `applyMerge`, 문자 분할 `toChars`
