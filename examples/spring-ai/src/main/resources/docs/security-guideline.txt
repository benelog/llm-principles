정보 보안 기본 지침

1. 계정과 비밀번호
모든 사내 시스템 계정의 비밀번호는 12자 이상으로 설정하고, 대문자, 소문자, 숫자, 특수문자를 각각 1자 이상 포함해야 한다. 비밀번호는 6개월마다 변경하며, 최근 3회 사용한 비밀번호는 재사용할 수 없다. 사내 주요 시스템(인사, 재무, 소스 저장소)에는 반드시 2단계 인증을 활성화한다.

2. 이메일 보안
발신자가 불분명한 메일의 첨부 파일은 열지 않는다. 급여, 인사 발령 등을 사칭한 피싱 메일이 자주 발생하므로, 의심스러운 메일을 받으면 본문 링크를 클릭하지 말고 보안팀(security@example.com)에 신고한다. 사내 문서를 외부로 전송할 때는 암호를 설정하고, 암호는 별도 채널로 전달한다.

3. 단말기 관리
업무용 노트북에는 회사가 승인한 소프트웨어만 설치할 수 있다. 개인 USB 저장 장치는 사용이 금지되며, 파일 이동이 필요하면 사내 파일 공유 시스템을 이용한다. 노트북 분실 시 즉시 보안팀에 신고하여 원격 초기화를 요청한다.

4. 개인정보 취급
고객의 개인정보는 업무상 필요한 최소 범위에서만 조회한다. 개인정보가 포함된 화면을 캡처하거나 개인 기기로 촬영하는 행위는 금지된다. 개인정보 처리 업무를 수행하는 직원은 매년 개인정보 보호 교육을 이수해야 한다.

5. 사고 신고
보안 사고를 발견하거나 의심되는 상황이 생기면 24시간 운영되는 보안 상황실에 즉시 신고한다. 신고를 이유로 불이익을 받지 않으며, 신속한 신고는 피해를 줄이는 데 큰 도움이 된다.
